# 喜好志

> 这是喜好志的事实源，`data/tastes.json` 由它生成（页面读 json，不读本文件）。
> 每条 = 一个 `### 名称`，下面跟几行 `字段: 值`；分类用 `## 分类名`。
> 字段：rating(1–5) / note / tags / since / private。`private: true` 的条目只在本地可见，部署时被剔除。
> 改完跑 `npm run data`（或 `npm run build`）重新生成 json。
>
> 说明：以下条目整理自 2026-10-10 的偏好访谈，note 尽量保留原话。rating 是按语气估的，待核对。
> 2026-10-10 补录：音乐类大半来自网易云歌单《欸-你可笑不喜欢的音乐》（214 首）的统计，
> rating 按“歌单里出现过几首”推的，只是个粗排序，不代表喜好程度；影剧/其他里带 b 站标签的来自她的公开主页。
> 字段多一个可选的 `link`（渲染成卡片上的一行链接）。
