# 喜好志

> 这一卷是口味地图：食物、饮品、音乐、影剧、书、城市，加 11 个常看的账号，一共 63 条。
> 主歌单攒了 214 首。
> 评分按访谈当时的语气估的，是主观粗排，不是硬指标；「关注」那一栏是账号清单，不评分。

> 这是喜好志的事实源，`data/tastes.json` 由它生成（页面读 json，不读本文件）。
> 每条 = 一个 `### 名称`，下面跟几行 `字段: 值`；分类用 `## 分类名`。
> 字段：rating(1–5) / note / tags / since / private。`private: true` 的条目只在本地可见，部署时被剔除。
> 改完跑 `npm run data`（或 `npm run build`）重新生成 json。
>
> rating 有两种来源，别混着看：
> 1) 访谈条目（食物、饮品、影剧、书、城市、其他，以及音乐里的「单曲循环」「山野里」「主歌单」）。
>    rating 按访谈当时的语气估的，属主观粗排，待核对。
> 2) 音乐里标了「歌单推」的艺人卡（花粥、梁博、AniFace、告五人、回春丹、毛不易、栗先达、陈奕迅）。
>    来自网易云歌单《欸-你可笑不喜欢的音乐》（214 首）的统计，rating 按歌单里出现过几首推，
>    只代表出现频次，不代表喜好程度。标签里的「歌单推 · N 首」就是次数。
> 3) 「关注」那一栏不评分（rating: 0，页面不显示星）。那是账号清单，不是喜好强度；
>    名字来自本人 2026-10-10 抄录的 b 站关注列表，见 `data/sources/tastes/bilibili-following.txt`。
> 4) 「书」那一栏的 rating 是粗排：微信读书标了称号的（最爱 / 常读常新 / 最爱玄幻）给 5；
>    阅读时长排前面的、单次读得最久的、标了「思考最多」「共读最多」的给 4；其余给 3。
>    原始数据见 `data/sources/tastes/wechat-reading.md`。
> 影剧里带 b 站标签的，来自她的公开主页。字段多一个可选的 `link`（渲染成卡片上的一行链接）。
>
> 本卷尚在增补。

## 食物

### 板栗红薯（蒸或烤）

rating: 5
featured: true
tags: 状态不好时会找, 粉糯
note: 状态不好时会主动去找的那一口。只认板栗红薯，蒸的烤的都行，要粉要糯。普通红薯太甜腻，流蜜的又甜过了头。

### 蒸鸡胸肉

rating: 3
tags: 健身, 日常
note: 平常自己做饭，多是蒸菜。鸡胸肉蒸好切片，和红薯、馒头、香蕉、鸡蛋、吐司轮着搭。练的人对吃其实没那么挑，图的是干净顶饿。

### 卤牛肉

rating: 3
tags: 健身, 日常
note: 蒸菜里的一味，卤透切片，配饭配馒头都行。这类吃食不必费什么心思，合口味就够。

### 蒸秋葵

rating: 3
tags: 健身, 日常
note: 蒸菜里的一味。黏液厚重，算是那一盘翠色里最有个性的一样，清淡却不寡。

### 蒸菜心

rating: 3
tags: 健身, 日常
note: 蒸菜里的一味。青绿的一把，蒸完还立得住，是整盘里最有菜味的那样。

### 啤酒鸭

rating: 3
featured: true
tags: 配饭
note: 问起能马上想到、适合配饭的那道菜。啤酒把鸭肉焖得酥透，酒气散尽只留一层香，汁拌进饭里最好。

### 菜籽油炒鸡

rating: 3
tags: 配饭
note: 和啤酒鸭一起被想起来的另一道下饭菜。菜籽油的香气比菜先到桌上，同样是一碗饭打底的菜。这样的菜好多，一次说不完。
