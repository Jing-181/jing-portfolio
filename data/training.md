# 训练档案

> 这是训练档案的事实源，`data/training.json` 由它生成（页面读 json，不读本文件）。
> 每条 = 一个 `### 标题`，下面跟几行 `字段: 值`；`## 年份` 只作分隔，不参与分类。
> 字段：
>   date    YYYY-MM，排序用（新的在前）
>   kind    分类。这一批是华为运动健康的月度汇总，所以按年份分（2026 年 / 2025 年 / …），
>           最上面那条总计写「总计」。以后补按天记的力量、跑步记录时，kind 写动作类型即可。
>   title   取 `### 标题`
>   metric  关键数据，一行写完，如「21.3 小时 · 25 次 · 7,722 千卡」
>   note    项目明细、状态、感受
>   tags    标签，逗号分隔
>   private true = 只在本地可见，部署时剔除
> 改完跑 `npm run data`（或 `npm run build`）重新生成 json。
>
> 数据来源：华为运动健康 14 张截图，2023-10 到 2026-10。原始数据照抄在
> `portfolio-docs/volumes/raw/huawei-health.md`。
> 「时长 / 次数 / 千卡」是当月全部运动的加总；项目明细按系统单列出来的抄，
> 距离用公里、时长用小时、不到一小时的原样写分秒。
> 截图里没有 2024 年 5 月，不是漏写。
>
> 这一卷还没完成。华为这边只有月度汇总，小米运动还没给，按天记的动作、配速、
> 主观感受也还没有。
