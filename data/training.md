# 训练档案

> 这是训练档案的事实源，`data/training.json` 由它生成（页面读 json，不读本文件）。
> 每条 = 一个 `### 标题`，下面跟几行 `字段: 值`。
> 字段：
>   date    YYYY-MM-DD，排序用（新的在前）
>   kind    力量 / 跑步 / 跑山 / 羽毛球 / 有氧恢复 / 其他
>   title   这条练的是什么，如「深蹲日」「滨江轻松跑」
>   place   在哪练的（可留空）
>   metric  关键数据，一行写完，如「深蹲 5×5 @100kg · 硬拉 3×3 @120kg」
>   note    主观感受、状态、恢复情况
>   tags    标签，逗号分隔
>   private true = 只在本地可见，部署时剔除
> 改完跑 `npm run data`（或 `npm run build`）重新生成 json。
>
> 下面两条是示例，用来展示一条记录长什么样；换成真实数据、或直接删掉即可。
