# 训练档案

> 这是事实源，`data/training.json` 由它生成（页面读 json，不读本文件）。
> 每条 = 一个 `### 标题`，下面跟几行 `字段: 值`。
> 字段：
>   date    YYYY-MM，排序用（新的在前）
>   kind    分类，用来筛。现在是「总计 / 年份 / 运动项目」三类混着，
>           年份写成「2026 年」，项目写「跑步」「力量」这类，总计那条写「总计」。
>   title   取 `### 标题`
>   metric  关键数据，一行写完
>   note    说明
>   tags    标签，逗号分隔
>   private true = 只在本地可见，部署时剔除
> 改完跑 `npm run data`（或 `npm run build`）重新生成 json。
>
> 这一卷是**总结**，不是流水。数据来自华为运动健康，截图覆盖 2023-10 到 2026-10；
> 逐月明细没有留档，只把总量、每年的形状、和每个项目的分量写成了下面这些条。
> 按天记的动作、配速、主观感受还没有；小米运动的数据也还没给。
> 截图里 2024 年 5 月是空的，不是漏写。
