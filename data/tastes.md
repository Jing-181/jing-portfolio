# 喜好志

> 外婆家的夏天，《武林外传》从早放到晚，一整个假期没换过台；后来是一套书连着读了
> 二十五天，一条歌单攒到 214 首。放在心上的东西不算多，一件一件看下来，
> **每件都还说得清喜欢的是哪一处**。

> 这一卷不列清单，只把几件东西拆开来看：喜欢的是它哪一部分，为什么是它；
> 其余贴边的另归各处，每样只留一句。

> 这是事实源，`data/tastes.json` 由它生成（页面读 json，不读本文件）。
> 第一个 `##` 之前那段 `>` 是卷首语（页面从 json 读，HTML 里不另写一份）。
> 每条 = 一个 `### 名称`，下面跟几行 `字段: 值`；分组用 `## 分组名`，紧跟的那行 `>` 是分组的小注。
> 字段：
>   kind      页面上的样子：深（一物一签的深看）/ 记（小一号的深看）/ 聚（一类，一行）/ 签（一句话）/ 线（走过的路）
>   tagline   一句话定性，显示在名称旁边
>   elements  从它身上抽出来的元素，写成 `标签=一句`，多个用 `|` 隔开；标签是把手，一句话别再重复标签
>   stops     只给「线」用，写成 `地点|地点|地点`，用 `|` 隔开；
>             `地点（游）` 旅游路过的，淡色小字；`地点（出差：甲、乙）` 在那儿出差时去过的地方
>   roll      只给「聚」用，一类的名单，用 ` · ` 连
>   note      正文，一段（元素已经说清的就不必再写）
>   tags      标签，逗号分隔。**值里不能出现逗号**（会被切开）
>   private   true = 只在本地可见，部署时剔除
> 改完跑 `npm run data`（或 `npm run build`）重新生成 json。
